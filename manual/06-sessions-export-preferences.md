# Manage Sessions, Export, And Preferences

Use this page to save work, relocate images, export tables, and change application defaults.

## Save A Session

Use `File -> Save Session` to write the current session.

Behavior:
- if the session already has a file path, `Save Session` updates that file
- if the session has never been saved, `Save Session` behaves like `Save Session As...`

Use `Cmd+S` or `Ctrl+S` to save quickly.

## Save To A New Location

1. Open `File -> Save Session As...`.
2. Choose the destination and file name.
3. Save the `.icescopy` file.

Use this when you want:
- a copy in a different location
- a renamed session
- a branch of the current work

## Open A Session

1. Open `File -> Open Session...`.
2. Select the `.icescopy` file.

The session restores:
- image paths and order
- cells
- sample catalog
- image-edit state
- result tables

Use this to resume work from:
- an incomplete annotation pass
- a review session after analysis
- a previously imported temperature-sync session

## Relink An Image Folder

Use this when image paths in a session no longer resolve.

1. Open the session.
2. Open `File -> Relink Images Folder...`.
3. Select the folder that contains the session images.

Current behavior:
- matches files by basename
- updates the session image paths
- refreshes the current display
- persists the new paths back into the open session file when possible

If the session was opened from an existing `.icescopy` file, relink writes the new paths back into that same file automatically.

Limit:
- relink is basename-based
- duplicate filenames in the chosen folder can lead to ambiguous matches

## Export Results

1. Open `File -> Output Results`.
2. Choose `Grayscale CSV...`, `Freeze CSV...`, `Temperature CSV...`, or `All CSVs...`.
3. Save the CSV file.

Available exports depend on what exists in the current session.

## Change Preferences

1. Open `Preferences`.
2. Select a category.
3. Change the required values.
4. Click `Save`.

Categories:
- `General`
- `Viewer`
- `Drawing`
- `Analysis`
- `Timeseries`
- `Timeline`

Use them by purpose:
- `General` for undo, sorting, and sample-name generation
- `Viewer` for image-count and zoom behavior
- `Drawing` for circle and grid defaults
- `Analysis` for freeze finding and cycle interpretation
- `Timeseries` for plot colors and line widths
- `Timeline` for timeline density and marker display

Recommended workflow:
- set circle and grid defaults before heavy annotation
- set freeze-finding and cycle preferences before repeated analysis tuning
- set timeline and plot styling only after the core workflow is stable

## Important Preferences

Common settings include:
- default circle radius
- default grid parameters
- sample name pattern
- freeze-finder parameters
- cycle warm-up hysteresis
- timeline density
- plot line widths

## Default Sort

The default sort preference controls how newly added images are ordered before you manually re-sort them.

Use it when your image sets usually arrive ordered by:
- filename
- filesystem time
- EXIF time

## Sample Name Pattern

Autogenerated sample names use a pattern.

Pattern rules:
- `#` inserts the sample number
- `\#` inserts a literal `#`
- `\\` inserts a literal backslash

Example:
- `Sample_#` produces `Sample_0`, `Sample_1`, and so on
