\chapter{Get Started}

Use this page to load images, create a session, and understand the main workspace.


\section{Before You Start}

\manuallead{Have these ready}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item an ordered image sequence
\item a writable location for the \texttt{.icescopy} session file
\item optional external temperature data files if you plan to import them later
\end{itemize}

\section{Core Workflow}

\manuallead{Use this order for a standard run}

\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Create a new session.
\item Add images or add an image folder.
\item Sort the image list if needed.
\item Annotate cells.
\item Assign samples if your experiment uses sample groups.
\item Run analysis.
\item Review the \texttt{Grayscale Plot} dock and the \texttt{Results Tables} dock.
\item Import external temperature data if needed.
\item Save the session.
\item Export result tables.
\end{enumerate}

\section{Start A New Session}

\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Open \texttt{File -> New Session}.
\item Add images with \texttt{File -> Add Images...} or \texttt{File -> Add Folder...}.
\item Check the image order in the \texttt{Images} dock.
\item Save the session with \texttt{File -> Save Session} or \texttt{File -> Save Session As...}.
\end{enumerate}

\manuallead{Result}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item the session is ready for annotation
\item the image list and frame slider are populated
\end{itemize}

\manuallead{Practical rule}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item save once near the start so later relink operations can write back into the same session file automatically
\end{itemize}

\section{Open An Existing Session}

\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Open \texttt{File -> Open Session...}.
\item Select the \texttt{.icescopy} file.
\item Review the restored image list, cells, samples, and results tables.
\end{enumerate}

If the session opens but images are missing:


\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Open \texttt{File -> Relink Images Folder...}.
\item Select the folder that contains the session images.
\end{enumerate}

\manuallead{Result}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item the saved working state is restored
\end{itemize}

\manuallead{What is restored}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item image paths and image order
\item cells and keyframe geometry
\item sample catalog entries
\item image-edit state
\item existing results tables
\end{itemize}

\manuallead{The viewer supports}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item one-image view
\item two-image view
\item three-image view
\end{itemize}

When two or three images are shown, you can switch between:


\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item left-right layout
\item top-down layout
\end{itemize}

\manuallead{The timeline is used for}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item frame navigation
\item keyframes
\item flags
\item changing the visible timeline resolution
\end{itemize}

Use the smaller timeline-resolution slider when the image sequence is long and you need finer control over the main frame slider.


\manuallead{Working pattern}

\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Use the large frame slider to scrub through the sequence.
\item Use the small resolution slider to zoom the visible timeline range when precise frame access is difficult.
\item Use the diamond button to mark keyframes when cell geometry changes across the run.
\item Use the flag button to mark frames that need review.
\end{enumerate}

\manuallead{Important}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item keyframes and flags are frame markers only
\item keyframes affect interpolated cell geometry
\item flags are review markers and are exported through \texttt{flag\_state} in the grayscale results
\end{itemize}

\item filename ascending
\item filename descending
\item created time
\item modified time
\item EXIF time

\manuallead{Use sorting carefully}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]

\section{Choose The Right Tool}

\manuallead{Use these tools by purpose}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item \texttt{Cursor}: inspect cells, select cells, assign samples, edit freeze frames

\section{Add One Cell}

\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Switch to \texttt{Add Cell}.
\item Move the preview circle over the well or droplet.
\item Click to place the cell.
\item Repeat for additional cells.
\end{enumerate}

Use this tool when wells are irregular or when you only need a few cells.


\section{Add A Grid}

\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Switch to \texttt{Grid Tool}.
\item Move the preview grid into position.
\item Adjust rows, columns, pitch, and tilt in the current tool settings.
\item Click to place the grid.
\end{enumerate}

Use this tool when the image has a regular layout.


\section{Edit Existing Cells}

\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Switch to \texttt{Edit Cell}.
\item Select the cell or group of cells to modify.
\item Drag or resize the selection as needed.
\end{enumerate}

Use \texttt{Edit Cell} for geometry only. Do not use it for sample assignment or freeze-frame editing.


\manuallead{Common uses}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item recenter circles after placement
\item adjust radius to match the actual droplet or well boundary
\item correct a full row or group after grid placement
\end{itemize}

\section{Use Keyframes When Cells Move}

Use keyframes when the droplet positions are not stable across the image sequence.


\manuallead{Typical cases}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item camera drift
\item tray motion
\item droplets shifting position over time
\item a layout that is stable at some frames but not all frames
\end{itemize}

\manuallead{How to use them}

\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Go to a frame where the cell positions are correct.
\item Toggle the keyframe marker on that frame with the diamond button near the timeline.
\item Adjust the cells for that frame.
\item Move to a later frame where the positions have drifted.
\item Toggle another keyframe.
\item Adjust the cells again for that frame.
\end{enumerate}

\manuallead{Behavior}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item if the current frame is a keyframe, that frame stores its own cell geometry
\item between two keyframes, cell positions and radii are interpolated
\item outside the keyframe range, the nearest keyframe geometry is used
\end{itemize}

\manuallead{Practical rule}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item use as few keyframes as needed to keep circles centered on the wells or droplets
\item add more keyframes only where the drift changes enough that interpolation is no longer accurate
\end{itemize}

\manuallead{Important}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item edits on a keyframe update that keyframe
\item edits on a non-keyframe frame do not automatically create a new keyframe
\item analysis uses the interpolated geometry across frames
\end{itemize}

\manuallead{Review method}

\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Add a keyframe near the start of the sequence.
\item Add another only when the circles visibly drift off target.
\item Scrub between the two keyframes and check the interpolation.
\item If interpolation is not accurate enough, insert another keyframe between them.
\end{enumerate}

\manuallead{Typical uses}

\section{Delete Cells}

\manuallead{Use either method}

\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Switch to \texttt{Delete Cells} and click cells to remove them.
\end{enumerate}

\manuallead{Or}

\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]

\section{Select Cells}

Use \texttt{Cursor} to select cells in the image.


\manuallead{Selection behavior}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item single click selects one cell
\item box selection selects multiple cells
\item selection in the image and selection in the \texttt{Cells} panel stay synchronized
\end{itemize}

You can also select cells while \texttt{Image Edit} is active. In that mode, selection is available for inspection, but image-edit controls remain visible.


\section{Edit Freeze Frames}

\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Switch to \texttt{Cursor}.
\item Select a cell.
\item Enter the freeze frame in the \texttt{Freeze Frame} field.
\item Press \texttt{Set} or press \texttt{Enter}.
\end{enumerate}

\manuallead{Result}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item the cell record is updated
\item the change is logged and undoable
\item the \texttt{Freeze Events} table is rebuilt from the current freeze-frame assignments
\end{itemize}

\manuallead{Use this when}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item the automatic detector missed a real freezing event
\item the detector called the wrong frame
\item a cell should be left without a freeze event
\end{itemize}

\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]

\item Select one or more cells.
\item Choose a sample in the \texttt{Sample ID} control.
\end{enumerate}

To create a new sample from the current context:


\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Use \texttt{New Sample}.
\end{enumerate}

Autogenerated sample names follow the pattern defined in Preferences.


\section{Use The Sample Catalog}

Use the \texttt{Sample Catalog} dock to manage the session-level sample list.


\manuallead{Current behavior}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item sample IDs are fixed numeric labels
\item sample names are editable in the table
\item sample assignment still happens in \texttt{Cursor}
\end{itemize}

\manuallead{Use it to}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item rename samples
\item add unused samples ahead of time
\item review the current sample list
\end{itemize}

\manuallead{Restriction}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item a sample cannot be deleted while any cells are still assigned to it
\end{itemize}

\manuallead{Why it matters}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item CSU temperature import matches external sample columns against current sample names
\item clear sample naming before import reduces manual cleanup later
\end{itemize}

\section{Use The Cells Panel}

The \texttt{Cells} panel is a read-only inspection and selection view.


\manuallead{It shows}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item \texttt{Cell ID}
\item \texttt{Sample ID}
\item \texttt{Sample Name}
\item \texttt{Freeze Frame(s)}
\end{itemize}

\manuallead{Use it to}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item review cell records
\item select cells from a list
\item compare cell metadata quickly
\end{itemize}

Do not use it for editing. Editing stays in \texttt{Cursor}.


\section{Recommended Annotation Order}

For most runs, use this order:


\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Add or grid the initial cells.
\item Clean up geometry with \texttt{Edit Cell}.
\item Add keyframes only if the image sequence drifts.
\item Assign samples in \texttt{Cursor}.
\item Rename samples in \texttt{Sample Catalog} if needed.
\item Run analysis.
\end{enumerate}

\texttt{Image Edit} includes:

\item exposure
\item contrast
\item crop

\section{Review The Histogram}

Use the histogram to inspect grayscale distribution before or after editing.


\manuallead{Behavior}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item the full-image histogram is shown in gray
\item if cells are selected, their histogram is overlaid separately
\item if no cells are selected, no red overlay is shown
\end{itemize}

The histogram is a review tool. It does not change the image by itself.


\manuallead{Use it to answer}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item whether the full image is clipped too dark or too bright
\item whether selected cells occupy a narrower grayscale range than the full image
\item whether exposure or contrast changes are separating droplet signal from background
\end{itemize}

\section{Adjust Exposure}

\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Switch to \texttt{Image Edit}.
\item Move the \texttt{Exposure} slider or edit the numeric value.
\end{enumerate}

Use exposure when the full sequence is too dark or too bright.


\manuallead{Behavior}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item exposure changes are applied to display and analysis
\item each committed change is undoable
\end{itemize}

\section{Adjust Contrast}

\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Switch to \texttt{Image Edit}.
\item Move the \texttt{Contrast} slider or edit the numeric value.
\end{enumerate}

Use contrast when wells or droplets are difficult to distinguish.


\manuallead{Behavior}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item contrast changes are applied to display and analysis
\item each committed change is undoable
\end{itemize}

\section{Crop The Image}

\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Switch to \texttt{Image Edit}.
\item Click \texttt{Crop}.
\item Adjust the crop box.
\item Click \texttt{Apply} or press \texttt{Enter}.
\end{enumerate}

\manuallead{To discard the current crop draft}

\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Click \texttt{Cancel}.
\end{enumerate}

\manuallead{To remove the committed crop}

\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Click \texttt{Reset}.
\end{enumerate}

\manuallead{Behavior}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item crop does not start automatically when you enter \texttt{Image Edit}
\item crop is committed only when you apply it
\item crop changes are logged individually for undo and redo
\end{itemize}

\section{Run Uniform Exposure}

Use uniform exposure when brightness drifts from frame to frame.


\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Switch to \texttt{Image Edit}.
\item Set the uniform-exposure area on a stable reference region.
\item Run uniform exposure.
\end{enumerate}

\manuallead{Choose an area that is}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item stable across frames
\item representative of the illumination you want to normalize
\item not dominated by changing ice or fluid behavior
\end{itemize}

\manuallead{Behavior}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item correction is per image
\item correction affects display and grayscale analysis
\item the current frame is used as the reference frame
\item \texttt{Run} and \texttt{Reset} are both undoable
\end{itemize}

\manuallead{Use a control area that is}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item stable across the sequence
\item representative of the illumination drift
\item not dominated by changing freezing behavior
\end{itemize}

\item the solid timeseries is the raw mean grayscale through time

\item a strong freezing event usually looks like a clear grayscale drop with a corresponding response in the dashed timeseries
\end{itemize}

Use the plot together with the image viewer:


\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Find a suspicious dip or peak in the plot.
\item Scrub to the corresponding image frames.
\item Decide whether the detector is responding to real freezing, noise, blur, or drift.
\end{enumerate}

\section{Tune Freeze Finding}

\manuallead{Freeze-finding parameters live in}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item \texttt{Preferences -> Analysis -> Freeze Finding}
\end{itemize}

Use the \texttt{Grayscale Plot} and the \texttt{Freeze Events} table together when tuning.


\manuallead{Recommended order}

\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Start with \texttt{Peak Width}.
\item Then adjust \texttt{Peak Prominence}.
\item Only after that, adjust the convolution settings if needed.
\end{enumerate}

\manuallead{Parameter guide}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item \texttt{Peak Width}
\end{itemize}

Increase it to reject narrow noisy dips. Decrease it if real freezing events are being missed because the detected dip is too narrow.


\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item \texttt{Peak Prominence}
\end{itemize}

Increase it to require a stronger event. Decrease it if obvious freezing dips are not being accepted.


\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item \texttt{Tail Extension Points}
\end{itemize}

Increase it if freezing happens near the end of the run and end-of-timeseries events are being missed.


\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item \texttt{Convolution Half Window Points}
\end{itemize}

Controls the width of the step kernel used to build the dashed convolution timeseries. Larger values make the detector respond to broader changes. \texttt{0} keeps the original whole-timeseries window behavior.


\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item \texttt{Convolution Ramp Points}
\end{itemize}

Softens the step kernel near the center. Increase it if the real grayscale drop is gradual or sloped rather than abrupt.


\manuallead{Tune by failure mode}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item too many false events:
\end{itemize}

increase \texttt{Peak Prominence} first, then increase \texttt{Peak Width}


\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item real freezing missed:
\end{itemize}

decrease \texttt{Peak Prominence} first, then decrease \texttt{Peak Width}


\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item late-run events missed near the end:
\end{itemize}

increase \texttt{Tail Extension Points}


\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item dashed timeseries reacts to very broad trends instead of sharp drops:
\end{itemize}

reduce \texttt{Convolution Half Window Points}


\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item dashed timeseries is too sharp for a gradual freeze transition:
\end{itemize}

increase \texttt{Convolution Ramp Points}


\manuallead{Practical workflow}

\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Run analysis with the current settings.
\item Inspect the raw timeseries and dashed convolution timeseries in \texttt{Grayscale Plot}.
\item Compare reported freeze events with the image sequence.
\item Adjust one parameter at a time.
\item Run analysis again and compare the result.
\end{enumerate}

Do not tune by table output alone. The plot is the faster way to see whether the convolution timeseries is reacting to real freezing or to noise.


\manuallead{Use a controlled tuning process}

\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Pick one representative cell that behaves clearly.
\item Tune one parameter at a time.
\item Re-run analysis after each change.
\item Check a few easy cells and a few difficult cells before accepting the new settings.
\end{enumerate}

\item Set \texttt{Reset After Warmed To (°C)} if the run contains repeated cooling and warming cycles.

\manuallead{Current TAMU behavior}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item reads image time from the PNG filename

\item optionally applies well-level calibration by cell ID
\item if no sample setup exists, all cells are treated as one output group
\item builds frozen counts from Icescopy freeze results
\end{itemize}

\manuallead{Interpretation}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item the workbook provides the temperature timeseries
\item the image filename provides the timestamp anchor for each frame
\item temperature is interpolated onto the image times before the output table is built
\end{itemize}

\section{Use Reset After Warmed To}

Use \texttt{Reset After Warmed To (°C)} when the experiment contains repeated cooling and warming cycles.


\manuallead{Meaning}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item once temperature warms back to the selected threshold, the next cooling segment is treated as a new cycle
\item counts are interpreted within each cycle instead of across the entire run
\item crossing the threshold counts; the timeseries does not need to hit the exact value
\end{itemize}

The cycle detector also uses the analysis preference \texttt{Cycle Warm-Up Hysteresis (°C)} to ignore tiny threshold jitter.


\manuallead{Choose this threshold deliberately}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item set it high enough that a genuine warm-up must occur before a new cycle starts
\item do not set it so low that tiny oscillations near the threshold create false cycle boundaries
\end{itemize}

\manuallead{Current blank-correction rule}

\item if a selected blank freezes at a CSU row, that blank event contributes to the CSU blank-correction logic from that point onward
\end{itemize}

\section{Temperature Import Looks Wrong}

\manuallead{Check these first}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item the correct importer was used
\item sample names match where required
\item the reset temperature is appropriate for the run
\item cycle warm-up hysteresis is not too small
\item current freeze annotations are correct
\end{itemize}

\manuallead{Remember}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item CSU uses the \texttt{.dat} file as the authoritative picture-to-time mapping
\item TAMU uses filename time plus interpolation from the Linkam timeseries
\end{itemize}

\manuallead{Also check}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item whether sample names were finalized before CSU import
\item whether blank samples were selected only for CSU
\item whether the current freeze frames are correct before import
\end{itemize}

\section{A New Cycle Appears At The Wrong Time}

\manuallead{Cause}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item reset detection depends on both \texttt{Reset After Warmed To (°C)} and \texttt{Cycle Warm-Up Hysteresis (°C)}
\end{itemize}

\manuallead{Action}

\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Review the chosen reset temperature.
\item Increase cycle warm-up hysteresis if minor temperature jitter is creating false cycle boundaries.
\end{enumerate}

\section{Result Tables Look Stale}

\manuallead{Cause}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item the session state changed after the table was generated
\end{itemize}

\manuallead{Action}

\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Re-run analysis after changing cells, freeze annotations, samples, or image-edit settings.
\item Re-run temperature import after changing freeze annotations or sample assignments.
\end{enumerate}

\manuallead{Notes}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item \texttt{Cell Edit} and \texttt{Image Edit} can preserve existing tables in the session state
\item preserved tables are not automatically recomputed
\item image add, image removal, and image reorder operations invalidate analysis results
\end{itemize}

\section{Cells Drift Off The Droplets During The Run}

\manuallead{Cause}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item the geometry changes across frames but only one static cell layout is defined
\end{itemize}

\manuallead{Action}

\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Add keyframes at frames where the layout visibly changes.
\item Edit cell geometry on those keyframes.
\item Scrub between keyframes and confirm the interpolation is accurate.
\item Re-run analysis after the geometry is corrected.
\end{enumerate}

\section{Freeze Finding Misses Real Events Or Calls Too Many}

\manuallead{Cause}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item the detector parameters do not match the signal shape in the current data
\end{itemize}

\manuallead{Action}

\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Use the \texttt{Grayscale Plot} instead of guessing from the tables alone.
\item Compare the solid grayscale timeseries and dashed convolution timeseries against the image sequence.
\item Adjust \texttt{Peak Prominence} and \texttt{Peak Width} first.
\item Adjust convolution parameters only after the basic event thresholding is close.
\end{enumerate}

\section{The Packaged App Is Large}

\manuallead{Cause}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item the application bundles PySide6, OpenCV, NumPy, Pandas, SciPy, and PyQtGraph
\end{itemize}

\manuallead{Result}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item a large bundle size is expected unless dependencies are reduced
\end{itemize}
