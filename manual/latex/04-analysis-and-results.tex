\chapter{Run Analysis, Review The Grayscale Plot, And Inspect Results}

Use this page to run grayscale analysis, inspect result tables, and export data.


\section{Run Analysis}

\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Load images.
\item Annotate cells.
\item Apply any required image edits.
\item Open \texttt{Analysis -> Run Analysis}.
\end{enumerate}

\manuallead{Result}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item the app processes the loaded image sequence frame by frame
\item result tables are refreshed from the current session state
\end{itemize}

\manuallead{Analysis uses}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item cell positions
\item sample assignments
\item image-edit adjustments
\end{itemize}

\manuallead{If cells move across the sequence}

\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Add keyframes before running analysis.
\item Adjust cell geometry at the key frames.
\item Let the app interpolate between them.
\end{enumerate}

If keyframes are not used, analysis uses the current static cell geometry for all frames.


\manuallead{Before you run}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item confirm image order
\item confirm circles are centered
\item add keyframes if the layout drifts
\item apply any exposure, contrast, crop, or uniform-exposure edits first
\item save the session if the run represents a major milestone
\end{itemize}

\section{Know What Invalidates Analysis}

These operations invalidate analysis results:


\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item adding images
\item removing images
\item sorting or reordering images
\end{itemize}

These operations can preserve existing tables in session state, but do not recompute them automatically:


\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item cell edits
\item image edits
\item sample edits
\end{itemize}

\manuallead{Practical rule}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item if the interpretation of the data changed, run analysis again
\end{itemize}

\section{Review Result Tables}

The \texttt{Results Tables} dock contains three tabs:


\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item \texttt{Measurements}
\item \texttt{Freeze Events}
\item \texttt{Freeze Count Timeseries}
\end{itemize}

\manuallead{Use them by purpose}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item \texttt{Measurements} for frame-by-frame grayscale and geometry output
\item \texttt{Freeze Events} for per-cell event indexing
\item \texttt{Freeze Count Timeseries} for time and temperature alignment after external import
\end{itemize}

\section{Measurements}

Use \texttt{Measurements} in \texttt{Results Tables} for per-frame grayscale values.


This table is the main frame-based output from analysis.


\manuallead{Current column structure}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item \texttt{file\_name}
\item \texttt{flag\_state}
\item \texttt{cell\_<id>\_grayscale}
\item \texttt{cell\_<id>\_circle\_x}
\item \texttt{cell\_<id>\_circle\_y}
\item \texttt{cell\_<id>\_circle\_radius}
\end{itemize}

\manuallead{Typical uses}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item inspect grayscale values by frame
\item review flagged frames
\item export frame-based data to CSV
\end{itemize}

\manuallead{Important}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item this table does not depend on EXIF time
\item time and temperature are added later through temperature import
\end{itemize}

\section{Freeze Events}

Use \texttt{Freeze Events} to review the image index where freezing was recorded.


\manuallead{Current columns}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item \texttt{cell}
\item \texttt{image\_index}
\item \texttt{image\_name}
\end{itemize}

This table is intentionally image-based. It does not mix in external time or temperature assumptions.


Manual freeze-frame edits also update this table.


\section{Freeze Count Timeseries}

Use \texttt{Freeze Count Timeseries} after a successful temperature import.


\manuallead{This table combines}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item image-derived freeze information
\item external time and temperature data
\end{itemize}

Do not expect this tab to appear before temperature import.


\section{Review The Grayscale Plot}

Use the separate \texttt{Grayscale Plot} dock to inspect timeseries across frames.


\manuallead{Typical checks}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item confirm that the grayscale timeseries looks reasonable
\item compare selected cells
\item inspect the convolution timeseries against the raw timeseries
\item verify freeze events against the image sequence
\end{itemize}

\manuallead{Use the plot for two different tasks}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item checking whether the grayscale signal itself is sensible
\item checking whether the detector is calling the right freezing frames
\end{itemize}

\manuallead{Read the timeseries this way}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item the solid timeseries is the raw mean grayscale through time
\item the dashed timeseries is the convolution-based edge-enhanced signal used to find sudden drops
\item a strong freezing event usually looks like a clear grayscale drop with a corresponding response in the dashed timeseries
\end{itemize}

Use the plot together with the image viewer:


\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Find a suspicious dip or peak in the plot.
\item Scrub to the corresponding image frames.
\item Decide whether the detector is responding to real freezing, noise, blur, or drift.
\end{enumerate}

\section{Tune Freeze Finding}

\manuallead{Freeze-finding parameters live in}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item \texttt{Preferences -> Analysis -> Freeze Finding}
\end{itemize}

Use the \texttt{Grayscale Plot} and the \texttt{Freeze Events} table together when tuning.


\manuallead{Recommended order}

\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Start with \texttt{Peak Width}.
\item Then adjust \texttt{Peak Prominence}.
\item Only after that, adjust the convolution settings if needed.
\end{enumerate}

\manuallead{Parameter guide}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item \texttt{Peak Width}
\end{itemize}

Increase it to reject narrow noisy dips. Decrease it if real freezing events are being missed because the detected dip is too narrow.


\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item \texttt{Peak Prominence}
\end{itemize}

Increase it to require a stronger event. Decrease it if obvious freezing dips are not being accepted.


\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item \texttt{Tail Extension Points}
\end{itemize}

Increase it if freezing happens near the end of the run and end-of-timeseries events are being missed.


\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item \texttt{Convolution Half Window Points}
\end{itemize}

Controls the width of the step kernel used to build the dashed convolution timeseries. Larger values make the detector respond to broader changes. \texttt{0} keeps the original whole-timeseries window behavior.


\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item \texttt{Convolution Ramp Points}
\end{itemize}

Softens the step kernel near the center. Increase it if the real grayscale drop is gradual or sloped rather than abrupt.


\manuallead{Tune by failure mode}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item too many false events:
\end{itemize}

increase \texttt{Peak Prominence} first, then increase \texttt{Peak Width}


\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item real freezing missed:
\end{itemize}

decrease \texttt{Peak Prominence} first, then decrease \texttt{Peak Width}


\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item late-run events missed near the end:
\end{itemize}

increase \texttt{Tail Extension Points}


\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item dashed timeseries reacts to very broad trends instead of sharp drops:
\end{itemize}

reduce \texttt{Convolution Half Window Points}


\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item dashed timeseries is too sharp for a gradual freeze transition:
\end{itemize}

increase \texttt{Convolution Ramp Points}


\manuallead{Practical workflow}

\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Run analysis with the current settings.
\item Inspect the raw timeseries and dashed convolution timeseries in \texttt{Grayscale Plot}.
\item Compare reported freeze events with the image sequence.
\item Adjust one parameter at a time.
\item Run analysis again and compare the result.
\end{enumerate}

Do not tune by table output alone. The plot is the faster way to see whether the convolution timeseries is reacting to real freezing or to noise.


\manuallead{Use a controlled tuning process}

\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Pick one representative cell that behaves clearly.
\item Tune one parameter at a time.
\item Re-run analysis after each change.
\item Check a few easy cells and a few difficult cells before accepting the new settings.
\end{enumerate}

\section{Export Result Tables}

\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Open \texttt{File -> Output Results}.
\item Choose \texttt{Grayscale CSV...}, \texttt{Freeze CSV...}, \texttt{Temperature CSV...}, or \texttt{All CSVs...}.
\item Save the CSV file.
\end{enumerate}

Available exports depend on the current session contents.


\section{Interpretation Notes}

Use these assumptions when reading the tables:


\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item grayscale analysis is frame-based
\item image-edit settings affect analysis, not just display
\item temperature-aware interpretation belongs in the \texttt{Freeze Count Timeseries} table, not in the core frame table
\end{itemize}
