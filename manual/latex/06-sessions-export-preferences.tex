\chapter{Manage Sessions, Export, And Preferences}

Use this page to save work, relocate images, export tables, and change application defaults.


\section{Save A Session}

Use \texttt{File -> Save Session} to write the current session.


\manuallead{Behavior}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item if the session already has a file path, \texttt{Save Session} updates that file
\item if the session has never been saved, \texttt{Save Session} behaves like \texttt{Save Session As...}
\end{itemize}

Use \texttt{Cmd+S} or \texttt{Ctrl+S} to save quickly.


\section{Save To A New Location}

\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Open \texttt{File -> Save Session As...}.
\item Choose the destination and file name.
\item Save the \texttt{.icescopy} file.
\end{enumerate}

\manuallead{Use this when you want}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item a copy in a different location
\item a renamed session
\item a branch of the current work
\end{itemize}

\section{Open A Session}

\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Open \texttt{File -> Open Session...}.
\item Select the \texttt{.icescopy} file.
\end{enumerate}

\manuallead{The session restores}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item image paths and order
\item cells
\item sample catalog
\item image-edit state
\item result tables
\end{itemize}

\manuallead{Use this to resume work from}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item an incomplete annotation pass
\item a review session after analysis
\item a previously imported freeze count timeseries session
\end{itemize}

\section{Relink An Image Folder}

Use this when image paths in a session no longer resolve.


\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Open the session.
\item Open \texttt{File -> Relink Images Folder...}.
\item Select the folder that contains the session images.
\end{enumerate}

\manuallead{Current behavior}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item matches files by basename
\item updates the session image paths
\item refreshes the current display
\item persists the new paths back into the open session file when possible
\end{itemize}

If the session was opened from an existing \texttt{.icescopy} file, relink writes the new paths back into that same file automatically.


\manuallead{Limit}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item relink is basename-based
\item duplicate filenames in the chosen folder can lead to ambiguous matches
\end{itemize}

\section{Export Results}

\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Open \texttt{File -> Output Results}.
\item Choose \texttt{Grayscale CSV...}, \texttt{Freeze CSV...}, \texttt{Temperature CSV...}, or \texttt{All CSVs...}.
\item Save the CSV file.
\end{enumerate}

Available exports depend on what exists in the current session.


\section{Change Preferences}

\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Open \texttt{Preferences}.
\item Select a category.
\item Change the required values.
\item Click \texttt{Save}.
\end{enumerate}

\manuallead{Categories}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item \texttt{General}
\item \texttt{Viewer}
\item \texttt{Drawing}
\item \texttt{Analysis}
\item \texttt{Timeseries}
\item \texttt{Timeline}
\end{itemize}

\manuallead{Use them by purpose}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item \texttt{General} for undo, sorting, and sample-name generation
\item \texttt{Viewer} for image-count and zoom behavior
\item \texttt{Drawing} for circle and grid defaults
\item \texttt{Analysis} for freeze finding and cycle interpretation
\item \texttt{Timeseries} for plot colors and line widths
\item \texttt{Timeline} for timeline density and marker display
\end{itemize}

\manuallead{Recommended workflow}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item set circle and grid defaults before heavy annotation
\item set freeze-finding and cycle preferences before repeated analysis tuning
\item set timeline and plot styling only after the core workflow is stable
\end{itemize}

\section{Important Preferences}

\manuallead{Common settings include}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item default circle radius
\item default grid parameters
\item sample name pattern
\item freeze-finder parameters
\item cycle warm-up hysteresis
\item timeline density
\item plot line widths
\end{itemize}

\section{Default Sort}

The default sort preference controls how newly added images are ordered before you manually re-sort them.


Use it when your image sets usually arrive ordered by:


\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item filename
\item filesystem time
\item EXIF time
\end{itemize}

\section{Sample Name Pattern}

Autogenerated sample names use a pattern.


\manuallead{Pattern rules}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item \texttt{\#} inserts the sample number
\item \texttt{\textbackslash{}\#} inserts a literal \texttt{\#}
\item \texttt{\textbackslash{}\textbackslash{}} inserts a literal backslash
\end{itemize}

\manuallead{Example}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item \texttt{Sample\_\#} produces \texttt{Sample\_0}, \texttt{Sample\_1}, and so on
\end{itemize}

\section{Preferences File}

\manuallead{Application preferences are stored in}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item preferences.xml
\end{itemize}

This file is global application configuration. It is not part of an individual session file.
