\chapter{Import Temperature Data}

Use this page to align image-derived freezing results with external temperature data.


\manuallead{Open temperature import from}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item \texttt{Analysis -> Import Temperature Data}
\end{itemize}

\section{Choose The Correct Importer}

\manuallead{Use}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item \texttt{CSU IS .dat import...} for CSU data files
\item \texttt{TAMU Linkam .xlsx import...} for TAMU Linkam workbooks
\end{itemize}

The core analysis stays frame-based. These importers add time and temperature later.


\section{Import CSU Data}

Use the CSU importer when the external \texttt{.dat} file contains the authoritative image-to-time mapping.


\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Open \texttt{Analysis -> Import Temperature Data -> CSU IS .dat import...}.
\item Select the CSU \texttt{.dat} file.
\item Select any blank samples if blank correction is required.
\item Set \texttt{Reset After Warmed To (°C)} if the run contains repeated cooling and warming cycles.
\item Confirm the import.
\end{enumerate}

\manuallead{Current CSU behavior}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item uses the \texttt{Picture} column to match images to temperature rows
\item matches samples by sample name
\item reports unmatched names
\item corrects both false negatives and false positives relative to the current image-based freeze results
\item allows blank-sample selection for CSU blank correction
\end{itemize}

\manuallead{Interpretation}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item the CSU \texttt{.dat} file is the authoritative time and temperature source
\item the app trusts the \texttt{.dat} picture-to-row association instead of EXIF time or file modified time
\item if a sample name does not match, that sample is reported instead of silently guessed
\end{itemize}

\section{Import TAMU Data}

Use the TAMU importer when image timestamps are encoded in filenames and temperature comes from a Linkam workbook.


\begin{enumerate}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item Open \texttt{Analysis -> Import Temperature Data -> TAMU Linkam .xlsx import...}.
\item Select the workbook.
\item Optionally select the calibration CSV.
\item Set \texttt{Reset After Warmed To (°C)} if the run contains repeated cooling and warming cycles.
\item Confirm the import.
\end{enumerate}

\manuallead{Current TAMU behavior}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item reads image time from the PNG filename
\item interpolates temperature from the Linkam temperature timeseries
\item optionally applies well-level calibration by cell ID
\item if no sample setup exists, all cells are treated as one output group
\item builds frozen counts from Icescopy freeze results
\end{itemize}

\manuallead{Interpretation}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item the workbook provides the temperature timeseries
\item the image filename provides the timestamp anchor for each frame
\item temperature is interpolated onto the image times before the output table is built
\end{itemize}

\section{Use Reset After Warmed To}

Use \texttt{Reset After Warmed To (°C)} when the experiment contains repeated cooling and warming cycles.


\manuallead{Meaning}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item once temperature warms back to the selected threshold, the next cooling segment is treated as a new cycle
\item counts are interpreted within each cycle instead of across the entire run
\item crossing the threshold counts; the timeseries does not need to hit the exact value
\end{itemize}

The cycle detector also uses the analysis preference \texttt{Cycle Warm-Up Hysteresis (°C)} to ignore tiny threshold jitter.


\manuallead{Choose this threshold deliberately}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item set it high enough that a genuine warm-up must occur before a new cycle starts
\item do not set it so low that tiny oscillations near the threshold create false cycle boundaries
\end{itemize}

\section{Understand Blank Correction}

Blank correction applies only to the CSU workflow.


Use it when selected samples should act as blanks.


No blank-correction path is used for TAMU.


\manuallead{Current blank-correction rule}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item if a selected blank freezes at a CSU row, that blank event contributes to the CSU blank-correction logic from that point onward
\end{itemize}

\section{Review The Output}

After import, review the \texttt{Freeze Count Timeseries} tab.


\manuallead{Typical columns include}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item \texttt{timestamp}
\item \texttt{temperature\_C}
\item \texttt{cycle}
\item \texttt{image\_name} or \texttt{picture}
\item optional corrected temperature columns
\item per-sample frozen counts
\end{itemize}

Use this table for downstream work such as:


\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item frozen count versus time
\item frozen count versus temperature
\item cycle-by-cycle interpretation for repeated freeze-thaw experiments
\end{itemize}

\section{Interpret Repeated Cycles}

\manuallead{For repeated freeze-thaw runs}

\begin{itemize}[leftmargin=*,itemsep=0.35em,topsep=0.4em]
\item use the \texttt{cycle} column
\item compute within-cycle quantities first
\item combine cycles later in downstream analysis if needed
\end{itemize}

Do not treat all cycles as one monotonic run unless that is physically valid for the experiment.
