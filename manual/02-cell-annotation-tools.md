# Annotate Cells

Use this page to place cells, edit existing cells, assign samples, and review cell records.

## Choose The Right Tool

Use these tools by purpose:
- `Cursor`: inspect cells, select cells, assign samples, edit freeze frames
- `Add Cell`: place one cell at a time
- `Grid Tool`: place a repeated array of cells
- `Edit Cell`: move or resize existing cells
- `Delete Cells`: remove cells
- `Pan and Zoom`: navigate the image

## Add One Cell

1. Switch to `Add Cell`.
2. Move the preview circle over the well or droplet.
3. Click to place the cell.
4. Repeat for additional cells.

Use this tool when wells are irregular or when you only need a few cells.

## Add A Grid

1. Switch to `Grid Tool`.
2. Move the preview grid into position.
3. Adjust rows, columns, pitch, and tilt in the current tool settings.
4. Click to place the grid.

Use this tool when the image has a regular layout.

## Edit Existing Cells

1. Switch to `Edit Cell`.
2. Select the cell or group of cells to modify.
3. Drag or resize the selection as needed.

Use `Edit Cell` for geometry only. Do not use it for sample assignment or freeze-frame editing.

Common uses:
- recenter circles after placement
- adjust radius to match the actual droplet or well boundary
- correct a full row or group after grid placement

## Use Keyframes When Cells Move

Use keyframes when the droplet positions are not stable across the image sequence.

Typical cases:
- camera drift
- tray motion
- droplets shifting position over time
- a layout that is stable at some frames but not all frames

How to use them:
1. Go to a frame where the cell positions are correct.
2. Toggle the keyframe marker on that frame with the diamond button near the timeline.
3. Adjust the cells for that frame.
4. Move to a later frame where the positions have drifted.
5. Toggle another keyframe.
6. Adjust the cells again for that frame.

Behavior:
- if the current frame is a keyframe, that frame stores its own cell geometry
- between two keyframes, cell positions and radii are interpolated
- outside the keyframe range, the nearest keyframe geometry is used

Practical rule:
- use as few keyframes as needed to keep circles centered on the wells or droplets
- add more keyframes only where the drift changes enough that interpolation is no longer accurate

Important:
- edits on a keyframe update that keyframe
- edits on a non-keyframe frame do not automatically create a new keyframe
- analysis uses the interpolated geometry across frames

Review method:
1. Add a keyframe near the start of the sequence.
2. Add another only when the circles visibly drift off target.
3. Scrub between the two keyframes and check the interpolation.
4. If interpolation is not accurate enough, insert another keyframe between them.

## Use Flags During Review

Use the flag button near the timeline to mark frames that need attention.

Typical uses:
- suspicious grayscale behavior
- frames with motion blur
- frames worth revisiting before export

Behavior:
- flags appear on the timeline
- `flag_state` is exported in the grayscale results table

## Delete Cells

Use either method:

1. Switch to `Delete Cells` and click cells to remove them.

Or:

1. Switch to `Cursor`.
2. Select one or more cells.
3. Press `Delete` or `Backspace`.

## Select Cells

Use `Cursor` to select cells in the image.

Selection behavior:
- single click selects one cell
- box selection selects multiple cells
- selection in the image and selection in the `Cells` panel stay synchronized

You can also select cells while `Image Edit` is active. In that mode, selection is available for inspection, but image-edit controls remain visible.

## Edit Freeze Frames

1. Switch to `Cursor`.
2. Select a cell.
3. Enter the freeze frame in the `Freeze Frame` field.
4. Press `Set` or press `Enter`.

Result:
- the cell record is updated
- the change is logged and undoable
- the `Freeze Events` table is rebuilt from the current freeze-frame assignments

Use this when:
- the automatic detector missed a real freezing event
- the detector called the wrong frame
- a cell should be left without a freeze event

## Assign Samples

1. Switch to `Cursor`.
2. Select one or more cells.
3. Choose a sample in the `Sample ID` control.

To create a new sample from the current context:
1. Use `New Sample`.

Autogenerated sample names follow the pattern defined in Preferences.

## Use The Sample Catalog

Use the `Sample Catalog` dock to manage the session-level sample list.

Current behavior:
- sample IDs are fixed numeric labels
- sample names are editable in the table
- sample assignment still happens in `Cursor`

Use it to:
- rename samples
- add unused samples ahead of time
- review the current sample list

Restriction:
- a sample cannot be deleted while any cells are still assigned to it

Why it matters:
- CSU temperature import matches external sample columns against current sample names
- clear sample naming before import reduces manual cleanup later

## Use The Cells Panel

The `Cells` panel is a read-only inspection and selection view.

It shows:
- `Cell ID`
- `Sample ID`
- `Sample Name`
- `Freeze Frame(s)`

Use it to:
- review cell records
- select cells from a list
- compare cell metadata quickly

Do not use it for editing. Editing stays in `Cursor`.

## Recommended Annotation Order

For most runs, use this order:
1. Add or grid the initial cells.
2. Clean up geometry with `Edit Cell`.
3. Add keyframes only if the image sequence drifts.
4. Assign samples in `Cursor`.
5. Rename samples in `Sample Catalog` if needed.
6. Run analysis.
