# Sample Metadata

Use samples to group cells from the same material or treatment. Metadata describes those groups in the session and exported freeze-count table. It does not change the brightness measured inside a cell.

Before starting, [draw the cells](Annotation-Workflow.md). You can enter sample information before analysis or after reviewing freeze events.

## Cell IDs, sample IDs, and names

| Item | Meaning | Example |
| --- | --- | --- |
| **Cell ID** | Identifies one measured circle across frames | Cell `12` |
| **Sample ID** | Identifies a group of cells | Sample `2` |
| **Sample name** | Editable text shown for that group | `Control` |
| **Sample long name** | A longer description | `Control preparation A` |

Two samples with the same name remain different groups if their IDs differ. Renaming a sample is different from assigning a cell to another sample.

Keep sample names **nonempty and distinct**. In the normal temperature-count grouping path, a catalog sample with an empty name is skipped. Distinct names also make import selections and exported headers easier to check.

## Create a sample and assign cells

1. Choose **Edit → Cursor Tool (A)**.
2. Select the required cells in the image or **Cells** panel. For several cells, use the selection methods in [Annotation Workflow](Annotation-Workflow.md).
3. In **Tool Options**, choose a **Sample ID**, or click **New Sample** to create a group and assign the selection.
4. Select a few cells individually and check their Sample ID.

If selected cells belong to different groups, the control shows **Mixed Selection**. Choosing a sample assigns the whole selected group to it.

To create an empty catalog entry first, open **Edit → Sample Catalog Manager** and click **Add**. Assign cells to it afterward. Adding an entry alone does not add cells or create a freeze event.

## Enter and check values

1. Open **Edit → Sample Catalog Manager**, or show **Window → Sample Catalog**.
2. Expand a sample to see its fields.
3. Edit a value, then finish the field by pressing **Tab** or clicking another field.
4. Set **Sample type** to `air`, `soil`, or `other` as appropriate. This controls which type-specific fields are editable.
5. Save the session and inspect the metadata rows in a fresh freeze-count export.

Dates use `YYYY-MM-DD HH:MM:SS`, such as `2026-01-15 09:30:00`. Numeric fields take the number alone; their labels specify units. A blank field remains missing information. Do not enter zero merely to avoid a blank.

Entering air volume, dilution, or dry mass does **not** make Icescopy calculate a concentration. See [Output Reference](Output-Reference.md) for what it actually exports.

## Built-in fields

These are the default definitions. A saved session can carry customized definitions.

| Display label | Saved/export key | Use |
| --- | --- | --- |
| Sample name | `sample_name` | Short group label |
| Sample long name | `sample_long_name` | Longer description |
| Sampling site | `sampling_site` | User-supplied site description |
| Collection start | `collection_start` | Start date and time |
| Collection end | `collection_end` | End date and time |
| Sample type | `sample_type` | `air`, `soil`, or `other` |
| Well volume (uL) | `well_volume_uL` | Microliters per well; shared by default |
| Dilution factor | `dilution` | Dilution information; available for all three sample types |
| Air volume (L) | `air_volume_L` | Liters; available for air samples |
| Filter fraction used (0-1) | `filter_fraction_used` | Fraction of the filter used; available for air samples |
| Suspension volume (mL) | `suspension_volume_mL` | Milliliters; available for air and soil samples |
| Dry mass (g) | `dry_mass_g` | Grams; available for soil samples |

The first six identity fields are fixed: their label, key, type, export setting, and order cannot be changed, and they cannot be deleted. `sample_id` and `cell_number` are generated by the app and cannot be added as custom keys. A field's availability is not validation that the entered value is scientifically appropriate; check its units and meaning for your experiment.

## Share a value across samples

Fields marked **[all]** use one value across the catalog. The default **Well volume (uL)** is shared.

To allow different well volumes:

1. Open **Preferences → Samples → Sample Metadata Fields**.
2. Find **Well volume (uL)** and clear **All**.
3. Save Preferences.
4. Return to the catalog and enter each sample's volume.

When **All** is checked, editing one sample changes that field for all samples. Review existing values before enabling sharing: it cannot preserve several different values as independent entries. **Sample name** cannot be shared.

## Add a custom field

For example, add a preparation note:

1. Open **Preferences → Samples → Sample Metadata Fields**.
2. Click **Add Field**.
3. Enter **Label** `Preparation note` and **Key** `preparation_note`.
4. Choose **Type** `text`. Custom types are `text`, `number`, and `datetime`.
5. Leave **Export** checked to include the field in the freeze-count CSV's sample-information rows. Check **All** only if every sample should share its value.
6. Use **Move Up** or **Move Down** to set its order, then save Preferences.
7. Enter values in the catalog and save the session.

Custom keys start with a lowercase ASCII letter and contain only lowercase letters, digits, and underscores. Keys must be unique. The label is for readers; the key identifies the field in saved data and exports. Keep keys stable when external scripts read them.

Changes apply to the active session and become defaults for new sessions. Previously saved sessions retain their own definitions, so opening one can show different fields.

## Rename, hide, or delete a field

For non-fixed fields:

- Change **Label** to improve visible wording while retaining the key.
- Clear **Export** to keep a field in the session but omit it from exported sample-information rows.
- Change **Key** only when you intend to change the saved/exported name; update scripts that use it.
- Use **Delete Field** to remove a non-fixed field. The app asks for confirmation when removed fields contain values.

Use **Save Session As...** before removing fields or changing shared-value settings if you need the old catalog. Hiding a field from export does not remove it from a saved session.

## Remove a sample

Select its catalog entry and click **Delete**. A sample assigned to cells cannot be deleted: reassign those cells first. Removing an unused entry does not remove image files.

## Update results after a change

| Change | Next step |
| --- | --- |
| Assign cells to different Sample IDs | Reimport temperatures to rebuild group counts, then export again |
| Edit names or descriptive fields | Save and export again; brightness analysis does not need repeating |
| Change exported fields | Check exported metadata and any downstream reader |
| Change geometry or freeze events | Follow the [result dependency guide](Concepts-and-Data-Flow.md#what-to-repeat-after-an-edit) |
