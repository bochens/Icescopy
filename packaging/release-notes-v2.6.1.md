# Icescopy 2.6.1

Use [**INP-toolkit 0.4.4**](https://github.com/bochens/inptk/releases/tag/v0.4.4) for INP concentration calculations. Install it separately and select its executable in **Preferences → INP toolkit client**.

- Compare the combined maximum likelihood estimation (MLE) curve with directly calculated, blank-corrected individual dilutions and their uncertainty.
- Mark water controls as **water blank** in the Sample Catalog.
- Set shared blank temperature limits and optionally apply blank correction only after the first blank freezes.
- Use consistent temperature limits with **Full range**, table edits, and plot controls.
- Keep the plot in place when switching control tabs.
