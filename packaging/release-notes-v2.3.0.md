# Icescopy 2.3.0

## Video import and sample metadata

- Analyze video recordings as well as image sequences.
- Add custom sample fields, including text, numbers, dates, and sample types.
- Save each session's sample fields with its `.icescopy` file.
- Share metadata values across samples with **Same for all**.
- Enter well volume in the Sample Catalog.
- Export sample metadata with total and frozen counts; unassigned cells share one set of count columns.
- Improve cell editing, saved drawing settings, and session templates.
