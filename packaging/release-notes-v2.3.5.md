# Icescopy 2.3.5

- Fix video support in the macOS app.
- Select analysis intervals with start and end markers on the timeline.
- Mark or unmark selected droplets as frozen at the current frame using the flag tool.
- Filter the frame list to show freezing events.
- Speed up analysis of long videos.

## Downloads

Save your work and close Icescopy before updating.

- **macOS, Apple Silicon:** [Icescopy-macos-arm64.zip](https://github.com/bochens/Icescopy/releases/download/v2.3.5/Icescopy-macos-arm64.zip). Unzip and move **Icescopy.app** to **Applications**. See [macOS opening instructions](https://github.com/bochens/Icescopy/blob/main/wiki/Installation-and-Setup.md#install-on-macos).
