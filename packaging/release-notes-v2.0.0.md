# Icescopy 2.0.0

Analyze freezing experiments with interactive droplet and well selection, brightness plots, freeze detection, saved sessions, and CSV exports.

- Draw and edit selections directly in the image.
- Adjust images and review freezing measurements in the app.
- Match freezing events to Colorado State University (CSU) `.dat` and Texas A&M University (TAMU) Linkam `.xlsx` temperature records.
- Save and reopen `.icescopy` sessions.

## Downloads

- **macOS, Apple Silicon:** [Icescopy-macos-arm64.zip](https://github.com/bochens/Icescopy/releases/download/v2.0.0/Icescopy-macos-arm64.zip). Unzip and move **Icescopy.app** to **Applications**. See [macOS opening instructions](https://github.com/bochens/Icescopy/blob/main/wiki/Installation-and-Setup.md#install-on-macos).
