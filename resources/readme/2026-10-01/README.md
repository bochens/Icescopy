# README figures — Icescopy 2.5.0

These are direct Qt widget captures of Icescopy, generated by `capture.py`. They contain no desktop, operating-system title bar, computer-use indicator, or pointer. The ML figure is cropped to the actual preferences page. No detections or interface elements are drawn onto the captures afterward.

- `droplet-selection.png`: the bundled General droplets 1.0.0 model runs through the app's detection controller with two selected examples. It adds fourteen cells. The selected examples remain cyan; new circles are green. The Console contains the actual completion summary.
- `ml-model.png`: Preferences → ML showing the bundled model and Browse control.

The capture uses the repository's public evaluation image and guidance circles, reads them without modification, and writes preferences only into a temporary directory. Display colors, line thickness, labels, and window layout are adjusted for readability. No session or analysis output is saved.

To reproduce with the app's Python environment, run from the repository root on macOS:

```sh
python resources/readme/2026-10-01/capture.py /path/to/new-figure-folder
```

The script refuses to overwrite existing figures. It does not alter the installed app or the user's preferences.
